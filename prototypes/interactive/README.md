# meeterm — Interactive design study 01

スマホ向けの画面構成と操作感を確認するための、依存なし・単一HTMLのモックです。
**製品のブラウザ版でも、ネイティブ端末の代替実装でもありません。**

## 開き方

`index.html` をブラウザで開きます。インストールやビルドは不要です。
ローカルHTMLを開けない環境では、リポジトリのルートから次を実行します。

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory prototypes/interactive
```

ブラウザで `http://127.0.0.1:8080` を開きます。配布ZIPを展開した場合は、そのフォルダで `--directory .` に置き換えます。
GitHubのファイル表示はソース閲覧用であり、モックを実行する公開URLではありません。

スマホ幅では画面いっぱい、広い画面ではレビュー用のスマホ枠と画面切替ナビゲーションを表示します。

## 反映した要件

- SSH接続先 → Workspace一覧 → paneタブ。セッション選択画面は設けない。
- 1 SSH先につき `meeterm` セッションひとつ。Workspace = tmux window、Terminal = tmux pane。
- Workspaceには名前とCodex実行中・入力待ちなどの状態を表示。paneタブにも名前と状態を表示。
- 端末ヘッダーは戻る、Workspace名、pane追加、paneを閉じる。
- 戻る・タブ切替でpaneの状態は消さない。pane終了には確認を挟む。

アイボリー、サンドブラウン、控えめなアンバー、チャコールの端末面を使用。ミーアキャットのマークは控えめに配置しています。
タブの具体的な寸法、補助キー、設定画面、文言は今回のデザイン提案であり、製品仕様を確定する変更ではありません。

## 試せる操作

`Home lab` → `meeterm` → `Shell` と開き、デモ入力欄で `help`、`pwd`、`git status` を試せます。
入力途中の文面と履歴はpaneごとに保持されます。補助キーとサンプルキーボードも操作できます。

接続先・Workspace・paneの追加、pane終了のキャンセル／確定、最後のpane終了に伴うWorkspace削除を試せます。
新しい接続先では、明示的なデモ用ホスト鍵確認を挟みます。
設定から文字サイズ変更、通信断と再接続、全データのリセットを試せます。

## 境界

実際のSSH接続、tmux制御、コマンド実行、Codexの状態検出は行いません。
端末の文面・状態・成功件数はすべてサンプルです。Ctrlの組み合わせとキーボードも表示デモで、ネイティブIMEの検証ではありません。

入力はメモリ内だけに保持し、再読み込みで消えます。秘密鍵・パスワードを扱う欄はありません。
実際の認証情報は入力しないでください。外部アセット、フォントファイル、ストレージ、分析SDK、ネットワーク通信への依存はありません。
CSPでも通信を禁止しています。ユーザー入力はHTMLエスケープして表示します。

本体のReact Native / Rust / SSH / tmux / native rendererには接続せず、変更も加えていません。
このHTMLの状態管理や端末文面表示を、本体のWebView端末へ転用しないでください。
製品の基準は引き続き `AGENTS.md`、`docs/PRODUCT.md`、`docs/ARCHITECTURE.md` です。

## ブラウザ検証

Python PlaywrightとChromiumが利用可能な環境で実行します。アプリ本体の依存関係は変更しません。

```bash
python prototypes/interactive/test_mock.py
# システムChromiumを指定する場合
CHROMIUM_PATH=/usr/bin/chromium python prototypes/interactive/test_mock.py
```

Playwright管理のブラウザを使用する場合は、先に `python -m playwright install chromium` を実行してください。
結果とスクリーンショットは隣接する `evidence/` に出力します。`MOCK_EVIDENCE_DIR` で出力先を変更できます。

初回検証は41項目成功。主導線、pane状態保持、追加／終了、確認ダイアログ、初回ホスト確認、再接続、入力エスケープ、文字サイズを確認しました。
320×680、375×812、393×852、430×932、768×900、1280×980の各サイズで4画面のページ全体の横はみ出しを確認しました。
ブラウザのJavaScriptエラーとモックからのネットワークリクエストは0件です。
4つの主要画面、サンプルキーボード、再接続、終了確認、デスクトップのレビュー枠のスクリーンショットを目視確認しています。

これはChromium上のモック検証です。Android/iOSアプリ、実機、ネイティブGPU、日本語IME、実SSH、実tmuxの検証結果ではありません。
