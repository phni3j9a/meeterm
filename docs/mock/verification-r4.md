# 第4版のHTML mock 検証記録

確認日: 2026-09-07 / 改訂版04

## 今回の変更と範囲

第3版のキャラクター、アイボリー、暖色チャコール、細罫線を維持し、増えたワークスペースを探して切り替え、元の位置へ戻る操作を改善した。AppllamaではAgendaとUlyssesを中心に検索・選択画面を追加調査した。[設計判断と参照画面](./research-r4.md) を別途記録している。

通常ホームに検索入口、検索時に入力欄と全ワークスペースの結果、ターミナル見出しに選択シートを追加した。検索語と通常／検索一覧の位置はサーバー別に保持する。選択一覧は長い名前を折り返し、選択中のチェックとターミナル数を表示する。「ワークスペースが多い」の12件を加え、プレビューは9状態になった。

対象は `docs/mock/index.html` の操作できるHTMLモック。ネイティブ製品、Rust、CI、SSH/tmux通信、OSのIME、実機GPUは今回の検証範囲外。ターミナル内のテスト成功表示は固定サンプルであり、この確認結果のログではない。

## 表示の確認

Ubuntu上で独立したChromeをPuppeteerから起動し、次を確認した。

| 範囲 | 結果 |
| --- | --- |
| 6サイズ × 2テーマ × 4主要画面 | 48通りでドキュメントの横はみ出しなし |
| 6サイズ × 2テーマ × 検索・選択シート | 24通りで横はみ出しなし、シートはプレビュー内に収まる |
| 主要画面・シートの可視操作部品 | 44×44px以上。サンプルQWERTYキーを寸法監査から除外 |
| 可視HTML入力欄 | 16px以上 |
| 高頻度操作とReduce Motion | 画面全体の登場アニメーションなし、動きを減らす指定を確認 |

主要画面の6サイズは320×640、390×844、600×800、844×390、1024×768、1440×1050。新画面では最小サイズを320×568として確認した。

Astra Highによる実装と別のAstra Highによるデザインレビューを実施。通常ホーム、両テーマの検索、結果、該当なし、選択シート、長い日本語名、デスクトップを画像で実見した。裸の件数表示へターミナル記号を添え、選択一覧では長い名前を全文表示できるよう修正した。確認範囲に残る重大な視覚不具合はない。

最終27画面を [previews](./previews/) に保存し、コンタクトシートと主要画面の大きい画像を実見した。72通りすべてを個別に目視したという意味ではない。[3画面の概要](./previews/overview.png) と [第3版との比較](./previews/comparison.jpg) は実際のブラウザ画像から作成している。

[操作録画](./previews/interaction.webm) は検索、日本語の結果、選択シート、pane切り替え、入力、検索画面への復帰、テーマ変更を含む。抽出フレームと末尾を実見した。Puppeteerには30fpsを指定したが、生成ファイルのffprobe実測値は25fps、390×844、15.56秒。WebMは画質を変えず再格納し、再生時間情報を付与した。実機のフレームレート検証ではない。

## 操作の確認

実装担当と別のレビュー担当が、新しい状態保持と既存の入力状態の組み合わせを検証した。独立機能レビューの19ケースは修正後すべて通過した。

- 12件のサンプルと、選択中も含めた検索対象。NFKC、全角英数、大小文字、前後空白、日本語での一致。
- 入力とcomposition中に検索inputのDOMとフォーカスを保持し、結果領域だけ更新する。
- 検索を閉じると検索前の一覧位置と検索ボタンのフォーカスを復元する。
- 検索語、検索中の状態、結果のスクロールはタブ・ターミナル往復後も保持し、別サーバーと混同しない。
- 通常一覧の位置をタブ往復で保持する。作業切り替えで「前回の続き」の対象が変わる場合、表示中の行の座標を保つ。確認例では行1件分の87pxを補正した。
- 選択シートは現在の作業を示し、閉じる／Escapeでターミナルのタイトルへフォーカスを戻す。
- ワークスペース・paneごとの選択pane、未送信入力、履歴、履歴選択中の下書き、出力のスクロールを切り替え後も保持する。
- 選択シートを介した切り替えでterminalのcompositionが中断されても、意図しない送信をせず入力を再開できる。
- プレビュー状態の変更で検索・一覧位置・一時キーボード状態をリセットする。見つかったShift／記号配列の初期化漏れを修正し、同じ操作で解消を確認した。テーマと文字サイズの設定は保持する。

IMEは合成compositionイベントでの検証。OSの実日本語IME候補ウィンドウは検証していない。
