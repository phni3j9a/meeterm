# 第3版のHTML mock 検証記録

確認日: 2026-09-07 / 改訂版03

## 今回の変更と範囲

ユーザーの参照画像をもとに、ミニマルな構成を保ってキャラクターを日常画面へ出す改訂を行った。既定をアイボリーへ変更し、暖色ニュートラルと茶系アクセントに統一。ホーム・サーバーの塗りカードを細罫線主体へ変更し、手描きのミーアキャットをホーム、サーバー、設定、空状態とレビュー表示へ配置した。ターミナルは両テーマから暗い作業面で開く。

対象は `docs/mock/index.html` の操作できるHTMLモック。ネイティブ製品・Rust・CI・SSH/tmux通信・OSのIMEや実機GPUは今回の検証範囲外。ターミナル内のテスト結果は固定サンプルであり、検証ログではない。

## 表示の確認

Ubuntu上のChromiumをPuppeteerで起動して確認。前回、組み込みBrowserが起動できなかったため、引き続き独立したローカルブラウザを使用した。

- 6サイズ（320×640、390×844、600×800、844×390、1024×768、1440×1050）×2テーマ×4主要画面、計48パターンでドキュメントの横はみ出しなし。
- 主要画面、サーバー追加、引き継ぎの可視操作部品は44×44px以上。QWERTYサンプルキーボードはこの寸法監査から除外。
- 可視HTML入力欄は16px以上。高頻度操作時の画面全体の登場アニメーションなし。Reduce Motionも確認。
- 主要画面、両テーマ、空状態、最初のサーバー、長いタブ名、キーボード、狭い画面を実際の画像で確認。48パターンすべてを個別に目視したという意味ではない。
- 最終17画面と操作録画を [previews](./previews/) に保存。録画は30fpsのブラウザ記録で、抽出フレームも実際に確認した。実機60fpsの検証ではない。

Astra Highの実装担当と別のAstra Highによる視覚レビューを使用した。ダークでキャラクターがネガ画像になる問題を修正し、砂色とアイボリーを保持。小さい画面ではキャラクターの領域を約30px縮めて次のワークスペースを見せる。最終レビューの確認範囲に残る重大なデザイン問題はない。

## 画像の合成

生成された素材の背景はRGBの白。ライトはmultiply、ダークはSVGフィルターで白いマットを除去して表示する。ダークの通常・空状態で、白矩形、黒い帯、過度な縁取りがないことを実視認した。素材を透過PNGとして生成できたという主張ではない。詳しくは [素材の記録](./assets/README.md)。

## 操作と回帰確認

第2版の8状態と操作を維持した。今回のデザイン変更後に、次を再実行して通過した。

- キーボードが開いた状態の初訪ペインで入力欄が見える。
- 長い名前の選択タブが表示範囲へ収まり、横スクロール位置を保持する。
- シートの初期フォーカスは見出し、操作ボタンのキーボードフォーカス表示は維持。
- 初めて追加したホスト・3台目のホストで、確認キャンセルの案内と再試行先が一致する。
- compositionイベント中の再描画後も入力を再開できる。OSの実IMEではなく合成イベントによる確認。
- 履歴選択中にペインを往復しても元の下書きへ戻れ、送信・clear後は履歴カーソルをリセットする。
- `file://` で埋め込みフォント・画像が読み込まれ、`pwd` のサンプル応答が動く。
- 検証時のページ例外・外部HTTPリクエストは0件。
