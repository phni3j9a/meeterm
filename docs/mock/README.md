# meeterm HTML mock

スマートフォン向けのSSH + tmuxクライアント「meeterm」の、操作できるデザインモックです。

## 開く

[`index.html`](./index.html) をブラウザで開いてください。CSS・JavaScript・SVG・日本語フォント・挿絵を埋め込んだ単一ファイルです。約1.2MBで、ビルドや外部CDNは不要です。HTMLをコピーするだけでオフラインでも表示できます。

ローカルサーバーを使う場合は、リポジトリのルートで次を実行します。

```bash
python3 -m http.server 8789 --bind 127.0.0.1 --directory docs/mock
```

同じマシンのブラウザから `http://127.0.0.1:8789` を開きます。サーバーへSSH接続して作業している場合は、手元のマシンでポート転送を使えます。

```bash
ssh -L 8789:127.0.0.1:8789 server@server-Macmini
```

ホスト名は普段のSSH接続先に合わせて置き換えてください。

## モックの範囲

- 全ワークスペースを同列に並べるホーム、名前検索、探していた位置への復帰
- ターミナル上部のワークスペース名からの作業切り替え
- ターミナルタブの切り替え、サンプル出力、入力操作
- サーバー選択シートと追加・確認のデモ
- 元の作業画面へ戻れる設定、外観・文字サイズの調整
- 再接続とPCへの引き継ぎのデモ
- 通常・12件の作業一覧・空の作業一覧・最初のサーバー・再接続中・接続失敗・切断後・初回ホスト確認・確認キャンセルの9状態

PC幅では操作のショートカットと状態選択を持つレビュー台、スマートフォン幅では全画面のアプリ表示になります。下部のアプリタブと「前回の続き」は置かず、ワークスペースを直接選ぶ構成です。

サーバー名から接続先を選び、ホーム右上の歯車から設定を開きます。ターミナルでは「…」からサーバー選択・設定・PCへの引き継ぎへ進めます。設定の戻るボタンは、開いたホームまたはターミナルへ戻ります。

「設定 → プレビューの状態」から9状態を選べます。状態の選択時は検索語・一覧位置・一時キーボード状態も含めてサンプルデータをリセットします。

「ワークスペースが多い」を選ぶと、12件から探す体験を確認できます。一覧見出しの虫眼鏡から「日本」や「meeterm」で検索し、結果を開いて戻ると検索語と位置を復元します。検索を閉じると通常一覧の元の位置へ戻ります。ターミナルでは上部の名前を押すと作業を切り替えられます。選択シートは6件以上で検索欄を表示し、長い名前も全文を確認できます。同じ接続中サーバーを選び直した場合はシートだけを閉じ、元の作業画面に留まります。

ターミナルでは `help`、`pwd`、`git status`、`clear` のサンプル応答を試せます。下書き・履歴・スクロール位置は接続先とターミナルごとに保持します。

接続情報、ホスト鍵、ターミナルの出力はサンプルです。実際のSSH接続やコマンド実行は行いません。入力内容はページ内のデモに使われ、リロードすると初期状態へ戻ります。実際の秘密鍵やパスワードは入力しないでください。

製品のReact Native/Rust/native構成を変更するものではありません。ブラウザ上のターミナル表示はデザイン確認用です。

## デザイン参考

[Appllama調査メモ](./research.md) に参考アプリ、画面ID、採用したパターンを記載しています。第5版はBear・Ulysses・Termiusを中心に、主一覧・編集・設定・サーバー管理の関係を調査しました。静止画候補90枚を実見し、過去の再参照と今回採用しなかった候補も区別して [第5版の情報設計](./research-r5.md) に記録しています。過去の調査枚数とは単純加算していません。

第3版では、参照画像をもとにミーアキャットをImageGenで新たに生成し、通常のワークスペース画面・サーバー・設定・空の状態へ配置しました。アイボリーを既定に、茶系アクセントと細い区切り線で整理しています。ターミナルは両テーマとも暗い作業面です。ターミナルには製品に同梱済みのM PLUS 1 Codeを使用しています。[素材とライセンス](./assets/README.md) も同梱しています。

第5版はこの外観と第4版の検索・状態保持を維持し、ワークスペースを主面、サーバーを一覧の対象、設定を補助画面として整理しました。全件一覧に面積を渡し、ホームで始めた再接続はホームで進めます。未確認ホストのキャンセルでは接続先を確定せず、元の作業を保持します。
